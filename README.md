# Invoice Extraction Automation System

## Business Problem

Businesses receive invoices from multiple suppliers in different formats. Manual data entry is slow and error-prone.

## Solution

This automation system extracts invoice data from PDF files and automatically loads it into a structured Excel database.

## Key Features

✔ Multi-supplier invoice support

✔ Automatic UPC extraction

✔ Quantity extraction

✔ Price extraction

✔ Power Query transformation

✔ One-click refresh

✔ Centralized Excel database
